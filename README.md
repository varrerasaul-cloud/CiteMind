# CiteMind

Official signed Windows releases for CiteMind.

The application source is maintained in a private repository. This public repository contains only the release channel required by installed CiteMind applications: Windows installers, updater signatures, and `latest.json`.

## Install

Download the latest signed Windows installer from [Releases](https://github.com/varrerasaul-cloud/CiteMind/releases/latest).

Existing CiteMind installations use this repository for signed automatic updates and do not need to be reinstalled.
